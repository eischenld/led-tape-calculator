About the calculator

The LED Tape Project Calculator is a beta planning tool for estimating LED tape connected load, power-supply capacity, current, feeder voltage drop, power-injection needs, controller sizing, and addressable IC/pixel requirements.

Beta status

This is an actively developing tool. Calculations should be verified against the LED tape, power supply, controller, conductor, and installation-method manufacturer documentation before installation.

What it is not

This calculator does not provide engineering approval, electrical-code compliance certification, or a substitute for applicable manufacturer instructions and local electrical requirements.

DMX Tools

The DMX DIP Switch Calculator converts DMX start addresses to binary DIP switch settings and can calculate an address from the switch positions.

Guides

The LED Tape Guides explain voltage selection, power supply sizing, voltage drop, power injection, tape types, pixel protocols, wire sizing, and DMX/network control.
