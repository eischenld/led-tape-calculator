Privacy

Version 0.1.0-beta does not require an account and does not send project inputs to an application database. Calculations run in your browser.

PDF export

The PDF/export feature generates a printable report in your browser. The beta site does not upload that report to an application server.

Analytics

The deployment package does not include a third-party analytics script. If Cloudflare Web Analytics is enabled for the deployed Pages project, Cloudflare may provide aggregate site-performance and traffic analytics under its service terms. This page should be reviewed if additional analytics, advertising, affiliate tracking, accounts, or saved-project features are added.

Future accounts

If login or cloud project storage is added later, this privacy notice will need to be updated before those features launch.
