Privacy

Version 0.3.14-beta does not require an account and does not send project inputs to an application database. Calculations run in your browser.

PDF export

The PDF/export feature generates a printable report in your browser. The beta site does not upload that report to an application server.

Analytics

This site uses Cloudflare Web Analytics and may use Google Analytics 4 through Cloudflare Zaraz to understand site usage and improve the calculator. Usage analytics may include page views, browser/device information, approximate geographic information, and limited interaction events such as Calculate, PDF Export, unit changes, tape-type changes, and Feedback clicks.

The calculator is configured not to intentionally send project names, email addresses, tape lengths, wattage entries, feeder distances, exact DMX addresses, or other project-specific calculator values with these custom usage events. DMX DIP calculator analytics use non-sensitive details such as interaction type, decoder layout, representability, and a coarse address range. The custom DMX usage event is limited to once per page load and does not use cookies or persistent identifiers.

Future accounts

If login or cloud project storage is added later, this privacy notice will need to be updated before those features launch.
